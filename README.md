# KAO I YOK · ต้นทุนต่อเตียง

เว็บคำนวณราคา โปร ต้นทุนคงที่ และกำไรต่อเตียง ของศูนย์ดูแลผู้สูงอายุเก้าอี้โยก
เก็บข้อมูลใน Supabase และต้อง login ก่อนใช้งาน

## ความสามารถ
- Login / สมัครสมาชิก / ลืมรหัสผ่าน (Supabase Auth, อีเมล + รหัสผ่าน)
- เก็บการคำนวณได้หลายชุด (สร้างใหม่ / ทำสำเนา / เปลี่ยนชื่อ / ลบ) บันทึกอัตโนมัติ
- เพิ่ม / แก้ / ลบ ห้องได้เอง (ชื่อห้อง, จำนวนเตียง, ราคารายเดือน / ล่วงหน้า 3 เดือน / 6 เดือน)
- เพิ่ม / แก้ / ลบ รายการต้นทุนคงที่เองได้
- สร้างโปรเองได้หลายโปร: ราคา, ระยะเวลา, จ่ายล่วงหน้าหรือไม่, จำกัดจำนวนเตียง, ราคาโปรและผู้พักแยกตามแต่ละห้อง, หลังหมดโปรต่อสัญญาแบบไหน (ใช้ราคาปกติของห้อง)

## ติดตั้ง (ครั้งแรก)
1. เปิด Supabase → **SQL Editor** → วางไฟล์ `supabase/schema.sql` แล้วกด Run
2. Supabase → **Authentication → URL Configuration** → ตั้ง Site URL เป็น URL ที่ใช้เปิดเว็บ
   (ถ้าไม่อยากยืนยันอีเมลตอนสมัคร ปิดได้ที่ Authentication → Sign In / Providers → Email → Confirm email)
3. เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ เช่น `npx serve .` หรือ deploy ขึ้น GitHub Pages / Netlify / Vercel

ค่า Supabase URL และ anon key อยู่ใน `config.js` (anon key เปิดเผยได้ ข้อมูลถูกป้องกันด้วย Row Level Security)
